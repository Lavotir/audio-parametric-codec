# NOT·CODEC

Параметрический текстовый аудиокодек с графическим интерфейсом. Программа превращает аудиофайл (MP3/WAV) в кастомный текстовый формат высокого разрешения `.not`, где для каждого шага времени (11.6 мс) математически зафиксированы точные частоты и громкости всех звучащих тонов. Обратное декодирование заново синтезирует звук из текста - в WAV-файл на диске или сразу в динамики через встроенный плеер.

В отличие от MIDI, который хранит только номера стандартных нот и зависит от внешнего синтезатора, `.not` хранит саму звуковую волну в параметрах, поэтому электронные эффекты, басы и шумы оригинального трека воспроизводятся с высокой точностью. Файл `.not` - это обычный текст UTF-8, который можно открыть в блокноте.

## Возможности

- Конвертация MP3/WAV/FLAC/OGG в текстовый формат `.not` с настраиваемой точностью (топ-N гармоник на кадр, шаг анализа по времени).
- Обратная конвертация `.not` в WAV (или в MP3, если в системе установлен ffmpeg).
- Встроенный плеер `.not`: читает текст и синтезирует звук в реальном времени прямо в динамики, без сохранения на диск, с регулировкой громкости и мгновенной остановкой.
- Современный тёмный интерфейс на customtkinter с живым осциллографом, прогресс-барами и подробными логами каждой операции.

## Требования

- Windows 10/11, Linux или macOS.
- Python 3.10 или новее. При установке Python обязательно поставьте галочку "Add Python to PATH".

## Установка библиотек

Откройте cmd и выполните одну команду:

```
pip install numpy soundfile sounddevice customtkinter
```

Дополнительно, по желанию:

```
pip install librosa
```

Библиотека librosa нужна только для чтения MP3 в том случае, если ваша версия soundfile (libsndfile) не умеет их читать. На свежих версиях Python и soundfile MP3 читаются и без неё.

Для экспорта в MP3 (вкладка декодирования, сохранение с расширением .mp3) нужен ffmpeg, установленный и добавленный в PATH. Без ffmpeg программа просто сохранит WAV рядом и предупредит об этом в логе.

## Как запустить

1. Откройте командную строку: нажмите Win+R, введите `cmd` и нажмите Enter.
2. Перейдите в папку, куда скачан файл программы, командой `cd`. Например:

```
cd C:\Users\User\Downloads
```

3. Запустите программу:

```
python not_codec.py
```

Если ваш файл называется иначе, укажите его реальное имя, например:

```
python Qwen_python_20260726_fplp6g1nk.py
```

Если команда `python` не распознаётся, переустановите Python с галочкой "Add Python to PATH" или используйте команду `py not_codec.py`.

## Как пользоваться

После запуска откроется окно с тремя вкладками.

Вкладка 1 "MP3/WAV → .NOT": выберите исходный трек, при желании задайте число гармоник (150-200 для максимальной точности) и разрешение времени, нажмите "Конвертировать". Файл `.not` появится рядом с исходником.

Вкладка 2 ".NOT → WAV": выберите файл `.not`, укажите путь сохранения (WAV или MP3) и нажмите "Конвертировать в аудио".

Вкладка 3 "Плеер .NOT": выберите файл `.not` и нажмите "Воспроизвести". Звук синтезируется на лету, кнопка "Стоп" прерывает воспроизведение мгновенно.

## Пример содержимого файла .not

```
#NOT 1.0
#SR 44100
#HOP 512
#FRAMES 15432
0|41.23:0.0512,439.98:0.5321,880.13:0.2114
1|41.19:0.0498,440.02:0.5488,880.09:0.1902
2|
```

Каждая строка - один шаг времени. Пары вида `440.02:0.5488` означают: синусоида с частотой 440.02 Гц и громкостью 0.5488. Пустая строка - кадр тишины.

## Возможные проблемы

- Ошибка `ModuleNotFoundError` - не установлены библиотеки, выполните команду `pip install numpy soundfile sounddevice customtkinter`.
- Ошибка `python не является внутренней или внешней командой` - Python не добавлен в PATH, переустановите его с галочкой "Add Python to PATH".
- Нет звука в плеере - проверьте устройство вывода по умолчанию в настройках Windows; частота дискретизации файла берётся из заголовка `.not` и поддерживается sounddevice автоматически.
- Конвертация MP3 завершается ошибкой - установите `pip install librosa`.
